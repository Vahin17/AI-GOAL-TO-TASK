# Plan 1.1: Next.js + Tailwind + shadcn/ui Scaffold

## Objective
Initialize the base Next.js application with Tailwind CSS and shadcn/ui, configuring it for a premium dark mode by default. This establishes the UI foundation for the 3-panel layout.

## Context
- .gsd/SPEC.md
- .gsd/ROADMAP.md

## Tasks

<task type="auto">
  <name>Initialize Next.js App</name>
  <files>package.json, tailwind.config.ts, tsconfig.json</files>
  <action>
    - Run `npx -y create-next-app@latest . --typescript --tailwind --eslint --app --use-npm --src-dir --import-alias "@/*"` (in non-interactive mode). Ensure you run it against the current directory if it's empty, or in a new `frontend` folder if preferred (let's use `./` to make it the root workspace).
    - Avoid creating generic filler files; just scaffold the bare minimum `app/page.tsx` and `app/layout.tsx`.
  </action>
  <verify>npm run build</verify>
  <done>Next.js app compiles successfully with Tailwind configured.</done>
</task>

<task type="auto">
  <name>Configure shadcn/ui & Dark Theme</name>
  <files>components.json, app/globals.css, tailwind.config.ts, lib/utils.ts</files>
  <action>
    - Run `npx -y shadcn-ui@latest init -y` with default style and slate colors.
    - Modify `app/globals.css` to force the dark theme globally by setting the `.dark` class variables on `:root` and ensuring the `body` background is a premium dark color (e.g., `#0A0A0A`) with white text.
    - Add utility `lib/utils.ts` (usually created by shadcn/ui).
    - Install `lucide-react` for icons if not already there.
  </action>
  <verify>cat app/globals.css</verify>
  <done>shadcn/ui is initialized and globals.css forces a dark premium theme without light mode flashes.</done>
</task>

## Success Criteria
- [ ] Next.js dev server runs without errors.
- [ ] Tailwind CSS is correctly parsing styles.
- [ ] shadcn/ui `components.json` is correctly configured at the root.
- [ ] Dark mode is the default and only theme applied.
