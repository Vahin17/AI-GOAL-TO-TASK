# Phase 2.3: Orchestration Pipeline & API Generation

## Goal
Wire the logic coordinating the AI response versus the fallback system, then mount the final REST API route via FastAPI and `uvicorn`.

## Context
The orchestrator acts as the "Traffic Cop". It routes the prompt to the selected LLM provider, catches any validation or timeout errors, and triggers `fallback_rules` if absolutely necessary. The API exposes this safely to the React Flow frontend client.

## File Targets

### `backend/ai/orchestrator.py`
- Initialize the selected `LLMProvider` based on `core/config.py`.
- Expose `generate_task_graph(goal: str) -> PlanGraphResponse`.
- Perform error handling (`try/except` for API/parsing errors), calling `fallback_rules.generate_fallback_plan()` on failure.

### `backend/api/router.py`
- `router = APIRouter()`.
- Define endpoint `POST /plan` parsing a lightweight Goal Pydantic request body, passing it to `generate_task_graph()`.

### `backend/main.py`
- FastAPI `app` init.
- Register `router`.
- Setup standard CORS middleware to permit `localhost:3000` or wildcard origins during development.

## Task Breakdown
1. [ ] Create `orchestrator.py` with try/catch pipeline.
2. [ ] Build the `api/router.py` with a health check and `POST /plan` route.
3. [ ] Instantiate the FastAPI app in `main.py` and attach the router and CORS middleware.
4. [ ] Verify dependencies (FastAPI, uvicorn) exist in virtual environment.

## Verification Steps
- Boot `uvicorn backend.main:app --reload`.
- Use the `/docs` Swagger UI endpoints, submit a mock goal, and verify the resulting nested structure arrives as expected.

## Success Criteria
- API boots successfully.
- Endpoint acts resiliently, outputting `PlanGraphResponse` json unconditionally (via generative AI or the fallback heuristic).
