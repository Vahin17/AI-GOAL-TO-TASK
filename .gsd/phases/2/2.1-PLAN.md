# Phase 2.1: Schemas & Base Configuration

## Goal
Establish the backend foundation by defining the configuration management and strict Pydantic schemas required to format AI outputs as a React Flow compatible graph.

## Context
React Flow strictly requires `nodes` and `edges` arrays. `nodes` must have at least `id`, `type`, `position` (x, y), and `data`. Edges must have `id`, `source`, and `target`. By enforcing this at the schema level, the AI guarantees a structured graph response. 

## File Targets

### `backend/core/config.py`
- Setup environment variables using `pydantic-settings` (e.g., `Settings` class).
- Include standard configs like `LLM_PROVIDER`, `OPENAI_API_KEY`, etc.

### `backend/schemas/models.py`
- `IntentOutput`: Pydantic model for core intent string and categorization.
- `TaskNode`: Pydantic model with fields matching React Flow's node specification (`id`, `type`, `position` with `x` and `y`, `data` with dictionary).
- `TaskEdge`: Pydantic model matching React Flow's edge spec (`id`, `source`, `target`).
- `GraphMetadata`: Captures intent string, confidence float, reasoning text.
- `PlanGraphResponse`: Nests `nodes` (List[TaskNode]), `edges` (List[TaskEdge]), and `metadata` (GraphMetadata).
